# Product Context

These files capture product intent, planning notes, and historical design decisions for Oak Report. They are useful background, but the implementation guides in `docs/` describe the current repo state.

- [Proposal](proposal.md) - original project pitch and target user journeys.
- [Specs](specs.md) - functional and non-functional requirements.
- [User stories](user_stories.md) - personas and user goals.
- [Platform selection](platform_selection.md) - evaluated technology options and target platform direction.
- [Repository injection](repository_injection.md) - current repository wiring notes.

When these documents discuss future-facing capabilities, treat them as roadmap context unless the current architecture and feature docs say they are implemented.
